# OPEN_HACKERS_AI

해커스 업무용 HTML 도구를 **로그인 없이 링크로** 여러 PC에서 함께 쓰기 위한 공개 공유 공간입니다.
GitHub Pages로 배포됩니다: https://siwan-ea.github.io/OPEN_HACKERS_AI/

## ⚠️ 공개 저장소 규칙
- 이 저장소의 모든 파일은 **인터넷에 공개**됩니다.
- **개인정보(이름·전화번호·성적), 설정 JSON, 원본 엑셀/PPT는 절대 올리지 않습니다.**
- 입력한 내용은 각 PC 브라우저에만 저장됩니다. PC 사이에는 「설정 저장 → 설정 불러오기」 JSON 파일로 옮깁니다.
